## Long description

Silo is a free, open-source mod manager for Farming Simulator 25, for players with a lot of mods. It reads your mods and your game log, so you can see what broke, what clashes and what's missing before the evening is gone.

- **Crashed? Start here.** After every run Silo reads `log.txt` and names the mod most likely behind the crash. When the log says nothing useful, *Find the problem mod* narrows it down, then puts your set back.
- **Checked before you launch.** Colliding filltypes, vehicle types or scripts, and the mods a friend's server needs, shown while they're still easy to fix.
- **Is it the real build?** Silo hashes an installed mod and compares it with the build its source published. It's a provenance check, not a virus scan.
- **Mod sets.** Keep a set per playthrough, switch between them, and share a set as a link or a file.
- **One catalog** across ModHub and GitHub, with the latest version found across both.

No account, no ads, no telemetry, and Silo never edits inside a mod. The app's source is on GitHub under the MIT license. Windows comes first; macOS and Linux builds exist, and testers are welcome.
